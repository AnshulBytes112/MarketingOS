# AI Brand Growth Engine - UX & Design Guidelines

## Primary Goal
The highest priority is UI/UX. The application must feel like a modern venture-backed startup (e.g., Linear, Framer, Stripe, Apple, Arc Browser, Vercel). Every design decision should prioritize visual elegance, user experience, simplicity, delight, performance, accessibility, consistency.

## Design Philosophy
- **Vibe:** Minimal, Elegant, Sophisticated, Calm, Confident, Fast, Modern, Creative, Premium.
- **Rules:** 
  - Less clutter, more breathing room (8px spacing system, large padding, perfect alignment).
  - Avoid generic admin dashboard layouts; every screen should feel custom designed.
  - Typography (Geist or Inter) creates hierarchy; do not rely just on colors.
  - Color System: Mostly neutral colors, ONE primary accent, ONE success, ONE warning, ONE danger. Very subtle gradients.
  - Micro-interactions: Everything should feel alive but subtle. Buttons press, cards lift. Animation duration ~150ms-250ms with natural easing.

## Component Guidelines
- **Customization:** Customize every shadcn/ui component. Nothing should look like a copied library.
- **Details:** Perfect shadows, border radius, icon alignment, empty states, and loading states.
- **Loading:** Use skeletons, optimistic updates, and smooth transitions instead of raw spinners.
- **Motion:** Motion communicates state changes and hierarchy. Never animate purely for decoration.
- **Layout:** Responsive from day one, collapsible sidebars, modern top navigation, sticky headers, command palette (Cmd+K).

## Quality Bar
Before finalizing any screen, ask:
1. Would this look out of place next to Linear or Apple?
2. Would this impress a senior product designer?
Iterate until the answer is "yes". The final result must be high-quality, polished, and immediately perceived as premium.
